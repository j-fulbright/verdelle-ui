# API coverage against shadcn/ui

One row per file in shadcn's base registry (`apps/v4/registry/bases/base/ui` in shadcn-ui/ui, checked 2026-11-10;
`_registry.ts` is not a component), compared with the Verdelle source: the `#[component]` signatures in
`crates/verdelle-ui/src/` and their doc comments. [`NAMING.md`](../crates/verdelle-ui/NAMING.md) explains the renames;
Behaviour gaps (keyboard, ARIA, animation) that are not about props are tracked as GitHub issues.

**Status**
- **full**: every part and prop shadcn's wrapper has has an equivalent here (a typed Rust spelling counts), possibly
  with extras.
- **partial**: something concrete is missing, listed in the row.
- **different**: the same job through a deliberately different API (one component instead of several parts, a prop
  where shadcn takes an element, a different upstream library); the row says how.
- **missing**: not built.

**How to read the prop columns.** shadcn's wrappers spread `...props` onto Base UI (or Radix, or a DOM element), so
every prop of the underlying primitive is available there. Verdelle exposes a typed subset of those props, so "absent"
below means "not a prop here", and Base UI props not mentioned in a row were not compared one by one. Native HTML
attributes (`aria-*`, `data-*`, `id`, `title`, event handlers) are not forwarded as a rule: components take `class`,
and the specific attributes named in their signatures (`id`, `name`, `aria_label`, ...). Leptos's `attr:` and spread
syntax can add attributes to a component's root element (for `Input` and `Textarea` the root is the frame, not the native
control). There is no `render` / `asChild` prop in general; the cases that need it have their own prop (`href` on
`Button`, `Item`, `SidebarMenuButton`; `as_child` on `Collapsible`, `RadioGroup`, `TooltipText`).
Sizes are the one `Size` enum (`XSmall`, `Small`, `Medium` = shadcn's `default`, `Large`) and an `icon_only` flag where
shadcn has `icon-*` sizes. Open state of overlays is an `RwSignal<bool>` (`open`) rather than `open` plus `onOpenChange`.

Counts: 64 shadcn files; 8 of them are the chat set (not built), 1 is Direction (out of scope).

## Not verified

  known to be absent.

- shadcn's registry changes; this table was written against the files as read on 2026-11-10.
